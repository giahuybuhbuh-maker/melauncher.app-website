Mọi phần một launcher thật cần có

Không phải bản rút gọn — từ xác thực tài khoản đến quản lý mod, xây theo đúng cách các launcher lớn vẫn làm.

Anti VIRUS & Spyware

Xác thực đúng chuẩn không VIRUS, không Spyware & XSTS. Người chơi game là số 1, cam kết không Trojan, 100% do người Việt phát triển.

Hỗ trợ mod Fabric

Chỉ cần tick một ô duy nhất, launcher tự tìm đúng bản Fabric Loader tương thích và ghép thẳng vào phiên bản bạn chọn.

Tự quản lý Java

Không cần tự cài JDK cho từng phiên bản — launcher tự động tải và cấu hình đúng bản Java runtime mà Minecraft yêu cầu.

Tinh chỉnh hiệu năng

Áp dụng sẵn bộ JVM flags tối ưu bộ nhớ (Aikar's flags), giúp ổn định FPS và giảm giật lag khi chơi lâu.

Cài đặt đầy đủ

Tùy chỉnh dung lượng RAM tối thiểu/tối đa, đường dẫn Java tùy chọn dễ dàng ngay bên trong giao diện cài đặt.

Kiểm tra file thông minh

Tự động quét và chỉ tải lại đúng những phần còn thiếu hoặc lỗi — không tải lại từ đầu mỗi lần mở launcher.

v0.1.7-alpha0.1 Windows 10/11 (64-bit)

ME Launcher cho Windows

Bản nén .zip và bộ cài Setup (.exe) đã đi kèm sẵn môi trường Java 25 Runtime bên trong — tải về là sử dụng được ngay, không cần cài đặt Java rời.

📌 Các bước cài đặt nhanh bản Portable (.zip):
1 Tải file .zip từ GitHub hoặc nút tải bên cạnh về máy.
2 Nhấp chuột phải vào file .zip → chọn Extract All (Giải nén).
3 Mở thư mục vừa giải nén → nhấp chuột phải vào ME Launcher.exe → Send to → Desktop (create shortcut).
4 Mở game trực tiếp từ biểu tượng ngoài màn hình chính (Desktop).
💡 Lưu ý nhỏ: Do bộ cài Setup.exe đóng gói bằng NSIS nên Google Drive có thể báo "Không thể quét virus". Bạn hoàn toàn yên tâm nhấn Tải xuống, hoặc chọn tải qua GitHub Releases để có tốc độ nhanh nhất!
