Mọi phần một launcher thật cần có

Không phải bản rút gọn — từ xác thực tài khoản đến quản lý mod, xây theo đúng cách các launcher lớn vẫn làm.

Anti VIRUS and Spyware

Xác thực đúng chuẩn không VIRUS và Spyware & XSTS, người chơi game là số 1 , không Trojan , đúng 100% người việt làm .

Hỗ trợ mod Fabric

Tick một ô, launcher tự tìm đúng bản Fabric Loader tương thích và ghép vào phiên bản bạn chọn.

Tự quản lý Java

Không cần tự cài JDK cho từng phiên bản — launcher tự tải đúng bản Java runtime Minecraft yêu cầu.

Tinh chỉnh hiệu năng

Áp dụng sẵn bộ JVM flags tinh chỉnh bộ nhớ (Aikar's flags), giảm giật khi chơi lâu.

Cài đặt đầy đủ

Chỉnh RAM tối thiểu/tối đa, đường dẫn Java tuỳ chỉnh, bật/tắt giao diện tối — ngay trong launcher.

Kiểm tra file thông minh

Chỉ tải lại đúng phần còn thiếu — không tải lại từ đầu mỗi lần mở launcher.

ME Launcher cho Windows

File nén .zip, đi kèm sẵn Java runtime bên trong — giải nén ra là chạy được ME Launcher.exe, không cần cài Java riêng.

Cách cài:vào github trên -> tải về → giải nén → mở thư mục vừa giải nén → chuột phải vào ME Launcher.exe → Send to → Desktop (create shortcut). Từ đó mở game ngay từ Desktop, không cần vào lại thư mục này nữa.
Lưu ý: Do file khá nặng, Google Drive có thể hiện thông báo "Không thể quét virus". Bạn cứ yên tâm chọn (#) nhé :). Thay bằng link file thật sau khi bạn nén thư mục build\dist\ME Launcher\ thành .zip và tải lên nơi lưu trữ (khuyên dùng GitHub Releases — miễn phí, có sẵn số liệu tải về).
